Platform setup

This page creates the first administrator of this platform. It is served by the core itself and disappears once setup is finished.

Keep this page open until the end: reloading it ends the setup session, and the setup code works once (a new one is minted with node bin/admin.js setup-code --new). A platform that requires more account fields than this page asks for: create the account with POST /system/create-user (admin key) or the account app, then sign in here.

1. Setup code

Enter the one-time setup code printed in the core's boot log (also in setup-code.txt next to its configuration file).

2. Checks

What this core sees of its configuration. A blocking item does not prevent finishing setup, but the platform will not serve as configured until it is fixed.

    3. First administrator

    Sign in with an account of this platform, or create one. That account receives the role owner for the whole platform.

    This account signs in with a second factor.

    Administrators of this platform sign in with a second factor. Add this account to an authenticator app with the secret below (or the link), then enter the code it shows.
